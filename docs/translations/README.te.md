# సన్‌షైన్ కేర్ లాగ్ / Sunshine Care Log

> వయస్సైన రోగుల కోసం ఉచితమైన, ఓపెన్-సోర్స్ రోజువారీ సంరక్షణ ట్రాకింగ్ సాధనం — ఇంటిలో సంరక్షకుల కోసం రూపొందించబడింది।

## ఇది ఏమిటి?

**ఇంటిలో సంరక్షకుల** వయస్సైన రోగుల రోజువారీ ఆరోగ్య డేటాను ఇంటిలో ట్రాక్ చేయడానికి సహాయం చేయడానికి రూపొందించిన ద్విభాషిక (చిరాకైన చైనీస్ 🇹🇼 / ఇండోనేషియన్ 🇮🇩) వెబ్ అప్లికేషన్ — ముఖ్యంగా కఠినమైన ద్రవ ব్యవస్థాపన అవసరమైన దీర్ఘకాలిక వ్యాధులతో బాధపడుతున్నవారు (గుండె విఫలత, డయాలిసిస్, శస్త్రచికిత్స-నంతర పునరుద్ధరణ).

ఇన్‌స్టాలేషన్ అవసరం లేదు. ఏదైనా స్మార్ట్‌ఫోన్ బ్రౌజర్‌లో పనిచేస్తుంది. డేటా Google Apps Script ద్వారా Google Sheets కు సమకాలీకరించబడుతుంది.

## విశేషతలు

- **ద్రవ సేవన ట్రాకింగ్** — నీరు, ఔషధ పానీయాలు, పోషక సంపూరకాలు, ఆహారం (రోజువారీ లక్ష్యం మరియు ప్రగతి బార్‌తో)
- **ద్రవ ఉత్పత్తి ట్రాకింగ్** — మూత్ర పరిమాణం + రంగు, ప్రేగు కదలికల స్థితి
- **మేధస్సుగా ఉన్న మూత్ర లక్ష్య అల్గారిథమ్** — నీటి సేవన లక్ష్యం ఆధారంగా अपेक్ష చేయబడిన మూత్ర ఉత్పత్తిని స్వయంచాలకంగా లెక్కించుకుంటుంది, మూత్రవర్ధక గుండులకు సమన్వయం చేయబడింది (×1.1–1.5 పరిధి) బర్ఖానా ఔషధం (×0.4–0.6 పరిధి)
- **ద్రవ అధిక లోడ్ హెచ్చరిక** — మొత్తం సేవన 1,200 సి.సి.ను అధిగమించినప్పుడు ఎరుపు హెచ్చరిక
- **వ్యాయామ లాగింగ్** — బాటిల్ లిఫ్ట్, పాదం ప్రెస్, మోకాలి బెండ్, స్ట్యాండ్ సహాయం (భద్రతా ప్రోటోకాల్ చెక్‌లిస్ట్‌తో)
- **రక్తపోటు మరియు గుండె రేటు** — ఉదయం మరియు సాయంకాల కొలతలు కొలత సూచనలతో
- **మలబద్ధత హెచ్చరిక వ్యవస్థ** — చివరి ప్రేగు కదలిక 60–72 గంటల పాటు ప్రతి 2 గంటలకు స్వయంచాలకంగా హెచ్చరికను ట్రిగ్గర్ చేస్తుంది, నిఠారుద్ధంలేని ఎనిమా ఉపయోగాన్ని నిషేధించే ద్విభాషిక భద్రతా సూచనలతో
- **ఔషధ స్థితి ట్రాకింగ్** — మూత్రవర్ధక అనిమేటర్లు మరియు జుల్మ్‌లు, క్లౌడ్‌లో నిలిచిపోయాయి
- **సమయం-ఆధారిత రిమైండర్ సిస్టమ్** — ఆర్‌పీ కొలత, వ్యాయామ స్లాట్‌లు మరియు నిద్రకు ముందు మూత్ర పరీక్ష కోసం స్మార్ట్ రిమైండర్‌లు
- **క్లౌడ్ సింక్** — Google Apps Script ద్వారా Google Sheets లో సంరక్షించిన అన్ని డేటా; బహు-సంరక్షక కుటుంబాలకు మద్దతు ఇస్తుంది
- **ఆశావాద UI** — సర్వర్ ప్రతిస్పందన కోసం వేచి ఉండకుండా రికార్డ్‌లు తక్షణమే కనిపిస్తాయి
- **వారానికి ఒకసారి శుభ్రతా రిమైండర్‌లు** — గృహ పరిశుభ్రత పనుల కోసం అంతర్నిర్మిత షెడ్యూల్

## ఇది ఎవరికి?

- ఇంటిలో వయస్సైన తల్లిదండ్రులు లేదా తాతమామలను చూసుకుంటున్న కుటుంబ సభ్యులు
- బహుళ భ్రమణ సంరక్షకుల కలిగిన కుటుంబాలు (ముఖ్యంగా భాష అవరోధాల ద్వారా)
- కఠినమైన ద్రవ పర్యవేక్షణ అవసరమైన పరిస్థితుల ఉన్న రోగులు (గుండె విఫలత, డయాలిసిస్, శస్త్రచికిత్స-నంతర పునరుద్ధరణ)

## సాంకేతికత స్టాక్

| లేయర్ | సాంకేతికత |
|-------|-----------|
| ఫ్రంటెండ్ | వనిల్లా HTML + జావాస్క్రిప్ట్ + Tailwind CSS |

## సెటప్ / స్వయం-హోస్టింగ్

1. ఈ రిపోజిటరీని ఫోర్క్ చేయండి
2. మీ స్వంత Google Apps Script బ్యాకెండ్‌ను నియోగించండి (`index.html` లో `GAS_URL` చూడండి)
3. డేటా నిల్వ కోసం Google Sheet సృష్టించండి
4. `index.html` లో `GAS_URL` మరియు `SPREADSHEET_URL` స్థిరాంకాలను నవీకరించండి
5. మీ ఫోర్క్‌లో GitHub Pages ను ప్రారంభించండి → పూర్తి

## ప్రేరణ

ఆవశ్యకత నుండి నిర్మితమైంది. కుటుంబ సభ్యుకు కఠినమైన ద్రవ ব్యవస్థాపనతో 24/7 ఇంటి సంరక్షణ అవసరమైనప్పుడు, ఇప్పటికే ఉన్న అప్లికేషన్‌లు చాలా సంక్లిష్టమైనవి, ఇంగ్లీషు-మాత్రమైనవి లేదా నెలసరి సందర్భాలకు అవసరమైనవి. ఈ సాధనం సంరక్షకులు రోగీపై దృష్టి పెట్టుకోగలిగేలా సరళమైన, ఉచితమైన, బహుభాషిక పరిష్కారాన్ని అందించడానికి లక్ష్యం రెంకిస్తుంది.

ప్లాన్‌చేసిన ఉభయోగాలు — ప్రతిదానికి ఒక ఓపెన్ సమస్య ఉందంటారు, సమాజ నుండి ఇన్‌పుట్ సుస్వాగతం:

- [ ] [#15](https://github.com/anwer3712/diet-log/issues/15) **AI-సహాయక ఆరోగ్య విశ్లేషణ** — ద్రవ సేవన, మూత్ర ఉత్పత్తి మరియు రక్తపోటు డేటా అంతటా అసాధారణ ట్రెండ్‌లను గుర్తించడానికి Claude ను సమీకృతం చేయండి మరియు ముడి సంఖ్యలను సాధారణ-భాష సంరక్షణ మార్గదర్శకానికి అనువదించండి
- [ ] [#16](https://github.com/anwer3712/diet-log/issues/16) **AI సంరక్షక Q&A** — సంరక్షకులు వారి స్వంత భాషలో ప్రశ్నలు నిరుద్ధరించుకోనుమతి ఇవ్వండి ("ఆమె యొక్క మూత్రం ఈ రోజు చీకటిగా ఉంది, నేను చింతపడాలా?") రోగీ యొక్క నిజమైన లాగ్ చేయబడిన డేటా ఆధారంగా
- [ ] [#17](https://github.com/anwer3712/diet-log/issues/17) **అదనపు భాష జతలు** — బహుసాంస్కృతిక సంరక్షణ కుటుంబాల కోసం ఇంగ్లీష్, వియత్నామీస్, టాగలోగ్, థాయ్
- [ ] [#18](https://github.com/anwer3712/diet-log/issues/18) **ఆఫ్‌లైన్ మోడ్** — అస్థిర కనెక్షన్‌ల కోసం సేవ కార్యకర్త కాషింగ్
- [ ] [#19](https://github.com/anwer3712/diet-log/issues/19) **ముద్రించదగిన వారానికి ఒకసారి నివేదికలు** — వైద్య సందర్శనల కోసం ఒక-పేజీ సారాంశాలు
- [ ] [#20](https://github.com/anwer3712/diet-log/issues/20) **మల్టీ-రోగి సపోర్ట్** — ఎక్కువ ఒకరిని ట్రాక్ చేసే కుటుంబాల లేదా చిన్న సంరక్షణ సुবిधाలకు
