# Sunshine Care Log（陽光照護日誌）

> 高齢者向けの無料オープンソースのデイリーケア記録ツール — 家族介護者向け。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Live Demo](https://img.shields.io/badge/Live-Demo-rose)](https://anwer3712.github.io/diet-log/)

---

## これは何ですか？

家庭で高齢者の毎日の健康データを記録するための二言語（繁体字中国語 🇹🇼 / インドネシア語 🇮🇩）ウェブアプリです。特に心不全、透析、手術後の回復など、厳格な液体管理が必要な慢性疾患をお持ちの患者さんに適しています。

インストール不要。スマートフォンのブラウザで動作します。データは Google Apps Script を介して Google スプレッドシートに同期されます。

---

## 主な機能

- **飲水・薬の液体・栄養補助飲料・食事の摂取記録** — 毎日の目標値と進捗状況を表示
- **尿量・尿の色・排便状況の記録** — 状態付きで追跡
- **インテリジェント尿量目標アルゴリズム** — 水分摂取目標に基づいて予想される尿量を自動計算し、利尿薬の有無に応じて調整（有：×1.1–1.5倍、無：×0.4–0.6倍）
- **液体過負荷警告** — 総摂取量が 1,200 c.c. を超えた場合に赤色警告
- **運動ログ** — ボトルリフト、足踏み、膝の曲げ伸ばし、立位補助（安全プロトコルチェックリスト付き）
- **血圧と心拍数** — 朝夕の測定値（測定ガイドライン付き）
- **便秘警告システム** — 最後の排便から 60–72 時間経過後、2 時間ごとに自動警告発生。浣腸の無監督使用を禁止する二言語安全指示付き
- **薬剤状態追跡** — 利尿薬と下剤、クラウドに保存
- **時間ベースのリマインダーシステム** — 血圧測定、運動時間帯、就寝前の尿チェックのスマートリマインダー
- **クラウド同期** — すべてのデータを Google Sheets に保存（Google Apps Script 経由）。複数介護者家庭に対応
- **楽観的 UI** — サーバー応答を待たずに記録が瞬時に表示されます
- **週間清掃リマインダー** — 家庭衛生タスクの組み込みスケジュール

## テクノロジースタック

| レイヤー | テクノロジー |
|-------|-----------|
| フロントエンド | Vanilla HTML + JavaScript + Tailwind CSS |
| バックエンド | Google Apps Script（サーバーレス） |
| データベース | Google Sheets |
| ホスティング | GitHub Pages（無料） |

フレームワークなし。ビルドツールなし。インストールする依存関係なし。任意のブラウザで直接開きます。

---

## セットアップ / 自己ホスティング

1. このリポジトリをフォーク
2. 独自の Google Apps Script バックエンドをデプロイ（`index.html` の `GAS_URL` 参照）
3. データ保存用の Google Sheet を作成
4. `index.html` の `GAS_URL` と `SPREADSHEET_URL` 定数を更新
5. フォークで GitHub Pages を有効化 → 完了

## 開発の動機

必要性から開発されました。家族が 24/7 の在宅介護と厳格な液体管理を必要とする際、既存のアプリは複雑すぎるか、英語のみか、月額料金がかかっていました。このツールは、介護者がアプリではなく患者に集中できるように、シンプルで無料、多言語のソリューションを提供することを目指しています。

## ロードマップ

計画中の改善 — それぞれがオープン問題で、コミュニティの意見を歓迎します：

- [ ] [#15](https://github.com/anwer3712/diet-log/issues/15) **AI 支援健康分析** — Claude を統合して液体摂取、尿量、血圧データの異常トレンドを検出し、生データを平易な介護ガイダンスに翻訳
- [ ] [#16](https://github.com/anwer3712/diet-log/issues/16) **AI 介護者 Q&A** — 介護者が自分の言語で質問できるようにする（例「彼女の尿が今日濃かったのですが、心配すべきですか？」）患者の実際に記録されたデータに基づいて
- [ ] [#17](https://github.com/anwer3712/diet-log/issues/17) **追加言語ペア** — 多文化介護世帯向けの英語、ベトナム語、タガログ語、タイ語
- [ ] [#18](https://github.com/anwer3712/diet-log/issues/18) **オフラインモード** — 不安定な接続用 Service Worker キャッシング
- [ ] [#19](https://github.com/anwer3712/diet-log/issues/19) **印刷可能な週報** — 医者の診察用 1 ページ概要
- [ ] [#20](https://github.com/anwer3712/diet-log/issues/20) **複数患者サポート** — 複数人を追跡する世帯や小規模介護施設向け
