# Sunshine Care Log（陽光照護日誌）

> 高齢者向けの無料オープンソースのデイリーケア記録ツール — 家族介護者向け。

---

## これは何ですか？

家庭で高齢者の毎日の健康データを記録するための二言語（繁体字中国語/インドネシア語）ウェブアプリです。特に体液管理が必要な慢性疾患の方に有用です。

インストール不要。スマートフォンのブラウザで動作します。データは Google Apps Script を介して Google スプレッドシートに同期されます。

---

## 主な機能

- 飲水・薬の液体・栄養補助飲料・食事の摂取記録（目標と進捗表示）
- 尿量・尿の色・排便状況の記録
- 利尿剤の有無に応じた尿量目標の自動算出
- 総摂取量が 1,200 c.c. を超えた場合の過負荷警告
- 運動ログ、血圧・心拍の計測、便秘警告システム
