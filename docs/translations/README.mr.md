# सनशाइन केअर लॉग / Sunshine Care Log

> वृद्ध रोगীसाठी एक विनामूल्य, ओपन-सोर्स दैनिक देखभाल ट्रॅकिंग साधन — कौटुंबिक काळजीसाठी तयार केलेले।

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Live Demo](https://img.shields.io/badge/Live-Demo-rose)](https://anwer3712.github.io/diet-log/)

---

## हे काय आहे?

एक द्विभाषिक (पारंपरिक चिनी 🇹🇼 / इंडोनेशियन 🇮🇩) वेब ऍप जो **कौटुंबिक काळजीसाठी** घरी वृद्ध रोगीच्या दैनिक आरोग्य डेटा ट्रॅक करण्यासाठी सहाय्य करण्यासाठी डिজाइन केलेले — विशेषत: जे दीर्घकालीन रोगांनी पीडित आहेत ज्यांना कडक द्रव व्यवस्थापन आवश्यक आहे (हृदय अपयशस्वता, डायलिसिस, शल्य क्रियेनंतर पुनरावृत्ती)।

कोणतीही स्थापना आवश्यक नाही। कोणत्याही स्मार्टफोन ब्राउজरवर कार्य करते। डेटा Google Apps Script द्वारे Google Sheets सह समन्वित केला जातो।

---

## वैशिष्ट्ये

- **द्रव सेवन ट्रॅकिंग** — पाणी, औषध पेये, पोषक पूरक, खाना (दैनिक लक्ष्य आणि प्रगती पट्टीसह)
- **द्रव उत्पादन ट्रॅकिंग** — मूत्र खंड + रंग, आंत्र हालचालींची स्थिती
- **बुद्धिमान मूत्र लक्ष्य अल्गोरिदम** — जल सेवन लक्ष्यावर आधारित अपेक्षित मूत्र उत्पादन स्वयंचलितरित्या मोजतो, मूत्रवर्धक औषधांसाठी समायोजित (×1.1–1.5 श्रेणी) औषध नाही (×0.4–0.6 श्रेणी)
- **द्रव अतिरिक्त बोझ सावधानी** — एकूण सेवन 1,200 सी.सी.अधिक असल्यास लाल सावधानी
- **व्यायाम लॉगिंग** — बोतल उठवणे, पाद दबवणे, गुडघे वाकणे, उभे होण्यासाठी सहाय्य (सुरक्षा प्रोटोकॉल चेकलिस्टसह)
- **रक्तदाब आणि हृदय दर** — सकाळ आणि संध्या मोजमाप मोजमाप मार्गदर्शनांसह
- **कब्जियतेचे सतर्कता प्रणाली** — शेवटच्या आंत्र हालचालीच्या 60–72 तास दरम्यान प्रत्येक 2 तासाला स्वयंचलितरित्या सावधानी ट्रिगर करते, द्विभाषिक सुरक्षा सूचनांसह जे निरीक्षणाशिवाय एनिमा वापरण्यास प्रतिबंधित करते
- **औषध स्थिती ट्रॅकिंग** — मूत्रवर्धक आणि रेचक, क्लाउडमध्ये कायम
- **वेळ-आधारित स्मरणीय प्रणाली** — रक्तदाब मोजमाप, व्यायाम स्लॉट आणि झोपण्यापूर्वी मूत्र तपासणीसाठी स्मार्ट स्मरणीय
- **क्लाउड समन्वय** — सर्व डेटा Google Sheets मध्ये Google Apps Script द्वारे साठवले जाते; बहु-काळजी घेणारे कुटुंब समर्थन करते
- **आशावादी ईयू** — सर्व्हरचे प्रतिसाद न होईपर्यंत तुरंत दिसू लागतात
- **साप्ताहिक स्वच्छता स्मरणीय** — घरेली स्वच्छता कार्यांसाठी अंतर्निर्मित वेळापत्रक

## हे कोणासाठी आहे?

- घरी वृद्ध माता-पिता किंवा दादा-दादींची काळजी घेणारे कुटुंबीय सदस्य
- एकाधिक घूमणारे काळजीसाठी कुटुंब (विशेषत: भाषा अडचणींचा सामना करत)
- रोगी ज्यांना कडक द्रव निरीक्षण आवश्यक आहे (हृदय अपयशस्वता, डायलिसिस, शल्य क्रियेनंतर पुनरावृत्ती)

## तंत्रज्ञान स्टॅक

| स्तर | तंत्रज्ञान |
|-------|-----------|
| फ्रंटएंड | व्यानिला HTML + JavaScript + Tailwind CSS |
| बॅकएंड | Google Apps Script (सर्व्हरलेस) |
| डेटाबेस | Google Sheets |
| होस्टिंग | GitHub Pages (विनामूल्य) |

कोणतेही फ्रेमवर्क नाही। कोणते बिल्ड साधन नाही। स्थापित करण्यासाठी कोणती अवलंबित्व नाही। कोणत्याही ब्राउজरमध्ये थेट उघडते.

---

## स्थापना / स्व-होस्टिंग

1. हे भांडार फोर्क करा
2. आपले स्वतःचे Google Apps Script बॅकएंड तैनात करा (`index.html` मध्ये `GAS_URL` पहा)
3. डेटा साठवणूकीसाठी Google Sheet तयार करा
4. `index.html` मध्ये `GAS_URL` आणि `SPREADSHEET_URL` स्थिरांक अपडेट करा
5. आपल्या फोर्कवर GitHub Pages सक्षम करा → पूर्ण

## प्रेरणा

गरजेने बांधले. जेव्हा कुटुंबीय सदस्याला कडक द्रव व्यवस्थापनासह 24/7 घर काळजी आवश्यक होती, तेव्हा विद्यमान अ्ऍप्लिकेशन्स अत्यंत जटिल, फक्त इंग्रजी किंवा मासिक सदस्यता आवश्यक होते. हे साधन एक सरल, विनामूल्य, बहुभाषिक उपाय प्रदान करण्याचा प्रयत्न करते जेणेकरुन काळजीसाठी रोगीवर लक्ष केंद्रित करू शकते, ऍप नाही.

- [ ] [#16](https://github.com/anwer3712/diet-log/issues/16) **कृत्रिम बुद्धिमत्ता काळजी प्रश्नोत्तर** — काळजीसाठीला आपल्या भाषेत प्रश्न विचारण्याचे अनुमति द्या (उदा. "तिचे मूत्र आज गडद होते, मी चिंता करावी का?") रोगीच्या प्रत्यक्ष नोंदणी डेटावर आधारित
- [ ] [#17](https://github.com/anwer3712/diet-log/issues/17) **अतिरिक्त भाषा जोड़े** — बहु-सांस्कृतिक काळजी कुटुंबांसाठी इंग्रजी, व्हिएतनामी, तागालोग, थाई
- [ ] [#18](https://github.com/anwer3712/diet-log/issues/18) **ऑफलाइन मोड** — अस्थिर कनेक्शनसाठी सेवा कार्यकर्ता कॅशिंग
