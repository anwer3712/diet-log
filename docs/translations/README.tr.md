# Sunshine Care Log

> Yaşlı hastalar için ücretsiz açık kaynak günlük bakım takip aracı — aile bakıcıları için.

---

## Nedir bu?

Evde yaşlı hastaların günlük sağlık verilerini takip etmek için ikidilli (Geleneksel Çince / Endonezce) bir web uygulaması.

---

## Özellikler

- Sıvı alım ve çıkım takibi, akıllı idrar hedef algoritması, sıvı aşırı yük uyarısı
- Egzersiz kaydı, tansiyon ve nabız ölçümleri, kabızlık uyarı sistemi
