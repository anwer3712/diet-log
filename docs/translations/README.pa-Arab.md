# ਪੰਜਾਬੀ (Arabic script)

نوٹ: یہ فائل مشینی ترجمہ ہے؛ انسانی جانچ ضروری ہے۔

# Sunshine Care Log

> بزرگ مریضوں کے لیے مفت اوپن سورس روزانہ کی دیکھ بھال کا ٹول — خاندانی نگہداشت کرنے والوں کے لیے۔

---

## یہ کیا ہے؟

گھریلو خاندانی نگہداشت کرنے والوں کو بزرگ مریضوں کے روزانہ صحت کے ڈیٹا کو ریکارڈ کرنے میں مدد دینے والی دو لسانی ویب ایپ (روایتی چینی / انڈونیشیائی)۔
