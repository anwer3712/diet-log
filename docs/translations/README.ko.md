# 선샤인 케어 로그 / Sunshine Care Log

> 노인 환자를 위한 무료 오픈 소스 일일 돌봄 추적 도구 — 가족 간병인을 위해 설계되었습니다.

[![Live Demo](https://img.shields.io/badge/Live-Demo-rose)](https://anwer3712.github.io/diet-log/)

## 이게 뭐예요?

**가족 간병인**이 집에서 노인 환자의 일일 건강 데이터를 추적하는 것을 돕기 위해 설계된 이중 언어(번체 중국어 🇹🇼 / 인도네시아어 🇮🇩) 웹 앱 — 특히 엄격한 체액 관리가 필요한 만성 질환을 앓는 환자 (심부전, 투석, 수술 후 회복).

설치가 필요하지 않습니다. 모든 스마트폰 브라우저에서 작동합니다. 데이터는 Google Apps Script를 통해 Google Sheets과 동기화됩니다.

---

## 기능

- **체액 섭취 추적** — 물, 의료용 음료, 영양 보충제, 식사 (일일 목표 및 진행률 표시줄 포함)
- **체액 배출 추적** — 소변량 + 색상, 배변 상태
- **지능형 소변 목표 알고리즘** — 물 섭취 목표에 따라 예상 소변 배출량을 자동으로 계산하며, 이뇨제 사용 여부에 따라 조정 (약물 사용 시: ×1.1–1.5배, 미사용: ×0.4–0.6배)
- **체액 과부하 경고** — 총 섭취량이 1,200 cc를 초과할 때 빨간색 경고
- **운동 기록** — 물병 들기, 발 누르기, 무릎 구부리기, 일어서기 지원 (안전 프로토콜 체크리스트 포함)
- **혈압 및 심박수** — 아침 및 저녁 측정 및 측정 지침
- **변비 경고 시스템** — 마지막 배변 후 60–72시간 동안 2시간마다 자동 경고 발생, 감시 없이 관장 사용을 금지하는 이중 언어 안전 지침 포함
- **약물 상태 추적** — 이뇨제 및 완하제, 클라우드에 저장
- **시간 기반 알림 시스템** — 혈압 측정, 운동 시간, 취침 전 소변 검사에 대한 스마트 알림
- **클라우드 동기화** — Google Apps Script를 통해 Google Sheets에 저장된 모든 데이터, 다중 간병인 가정 지원
- **낙관적 UI** — 서버 응답을 기다리지 않고 즉시 기록 표시
- **주간 청소 알림** — 가정 위생 작업을 위한 내장 일정

## 누구를 위한 것인가요?

- 집에서 노인 부모나 조부모를 돌보는 가족 구성원
- 여러 명의 교대 간병인이 있는 가정 (특히 언어 장벽을 넘어서)
- 엄격한 체액 모니터링이 필요한 환자 (심부전, 투석, 수술 후 회복)

## 기술 스택

| 계층 | 기술 |
|-------|-----------|
| 프론트엔드 | Vanilla HTML + JavaScript + Tailwind CSS |
| 백엔드 | Google Apps Script (서버리스) |
| 데이터베이스 | Google Sheets |
| 호스팅 | GitHub Pages (무료) |

프레임워크 없음. 빌드 도구 없음. 설치할 종속성 없음. 모든 브라우저에서 직접 열립니다.

---

## 설정 / 자체 호스팅

1. 이 리포지토리를 포크하세요
2. 자체 Google Apps Script 백엔드 배포 (`index.html`에서 `GAS_URL` 참조)
3. 데이터 저장용 Google Sheet 생성
4. `index.html`에서 `GAS_URL` 및 `SPREADSHEET_URL` 상수 업데이트
5. 포크에서 GitHub Pages 활성화 → 완료

## 동기

필요에서 비롯되었습니다. 가족 구성원이 엄격한 체액 관리로 24/7 재택 돌봄이 필요할 때, 기존 앱은 너무 복잡하거나 영어만 지원하거나 월간 구독이 필요했습니다. 이 도구는 간병인이 앱이 아닌 환자에게 집중할 수 있도록 간단하고 무료이며 다국어 솔루션을 제공하는 것을 목표로 합니다.

계획된 개선 사항 — 각각 열린 문제이며 커뮤니티 의견을 환영합니다:
