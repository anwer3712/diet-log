# 阳光照护日志 / Sunshine Care Log

> 为老年患者提供的免费开源日常护理追踪工具 — 专为家庭护理人员设计。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Live Demo](https://img.shields.io/badge/Live-Demo-rose)](https://anwer3712.github.io/diet-log/)

---

## 这是什么？

一个双语（繁体中文 🇹🇼 / 印尼文 🇮🇩）网页应用程序，旨在帮助**家庭护理人员**在家中追踪老年患者的日常健康数据 — 尤其是那些患有需要严格液体管理的慢性疾病的患者（心力衰竭、透析、手术后恢复）。

无需安装。可在任何智能手机浏览器上使用。数据通过 Google Apps Script 同步到 Google Sheets。

---

## 功能

- **液体摄入追踪** — 水、药物饮料、营养补充品、食物（包含每日目标和进度条）
- **液体输出追踪** — 尿量 + 尿色、排便状况及状态
- **智能尿量目标算法** — 根据水分摄入目标自动计算预期尿量，并根据利尿药物使用情况调整（使用：×1.1–1.5 倍；不使用：×0.4–0.6 倍）
- **液体超负荷警告** — 当总摄入超过 1,200 c.c. 时发出红色警告
- **运动记录** — 宝特瓶举起、脚踩、膝盖弯曲、站立辅助（含安全检查清单）
- **血压与心率** — 早晚测量，含测量指南
- **便秘警告系统** — 最后排便后 60–72 小时间，每 2 小时自动触发警告，提供双语安全指示（禁止无人监督使用灌肠）
- **药物状态追踪** — 利尿药物和泻药，数据保存到云端
- **时间基础提醒系统** — 血压测量、运动时段、睡前尿液检查的智能提醒
- **云端同步** — 所有数据保存到 Google Sheets（通过 Google Apps Script），支持多护理人员家庭
- **乐观型用户界面** — 记录立即出现，无需等待服务器响应
- **每周清洁提醒** — 内置家庭卫生工作排程

## 适用对象？

- 在家照护年迈父母或祖父母的家庭成员
- 有多名轮流护理人员的家庭（特别是跨越语言障碍的情况）
- 需要严格液体监测的患者（心力衰竭、透析、手术后恢复）

## 设置 / 自行部署

1. Fork 此仓库
2. 部署您自己的 Google Apps Script 后端（见 `index.html` 中的 `GAS_URL`）
3. 创建用于数据存储的 Google Sheet
4. 更新 `index.html` 中的 `GAS_URL` 和 `SPREADSHEET_URL` 常数
5. 在您的 fork 上启用 GitHub Pages → 完成

## 开发动机

出于必要而开发。当家庭成员需要 24/7 在家护理并进行严格液体管理时，现有应用程序要么过于复杂、只有英文版本，要么需要按月付费。这个工具的目标是：提供简单、免费、多语言的解决方案，让护理人员能专注于患者，而非应用程序本身。

## 路线图

计划中的改进 — 每项都是开放议题，欢迎社区贡献意见：

- [ ] [#15](https://github.com/anwer3712/diet-log/issues/15) **AI 辅助健康分析** — 整合 Claude 以检测液体摄入、尿量和血压数据的异常趋势，并将原始数据转译为平白易懂的护理指南
- [ ] [#16](https://github.com/anwer3712/diet-log/issues/16) **AI 护理人员问答** — 让护理人员用自己的语言提问（例如"她今天尿液很深，应该担心吗？"），基于患者实际记录的数据回答
- [ ] [#17](https://github.com/anwer3712/diet-log/issues/17) **更多语言对** — 英文、越南文、他加禄文、泰文，适用于多元文化护理家庭
- [ ] [#18](https://github.com/anwer3712/diet-log/issues/18) **离线模式** — 用 Service Worker 缓存解决不稳定连线问题
- [ ] [#19](https://github.com/anwer3712/diet-log/issues/19) **可打印周报** — 一页纸总结，用于医生看诊
- [ ] [#20](https://github.com/anwer3712/diet-log/issues/20) **多患者支持** — 家庭或小型护理设施追踪多人
