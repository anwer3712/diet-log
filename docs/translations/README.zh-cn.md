## 这是什么？

一个双语（繁体中文 🇹🇼 / 印度尼西亚语 🇮🇩）的 web 应用，帮助家庭照护者记录老年人在家中的日常健康数据，尤其适用于需要严格液体监测的慢性病患者。

无需安装。可在任何智能手机浏览器中运行。数据通过 Google Apps Script 同步到 Google 表格（Google Sheets）。

---

## 功能

- 液体摄入记录（饮水、药物液体、营养补充、餐食，带每日目标与进度条）
- 液体排出记录（尿量与颜色、大便情况）
- 智能尿量目标算法（根据饮水目标自动计算预期尿量，服用利尿剂时乘以 1.1–1.5，否则 0.4–0.6）
- 液体超载警告（总摄入超过 1200 c.c. 时发出红色警报）
- 运动记录（瓶举、脚踏、膝盖弯曲、站立辅助，含安全协议检查表）
- 血压与心率记录（早晚测量，含测量指导）
- 便秘提醒系统（最后一次排便后 60–72 小时间隔，每 2 小时触发警告，并有双语安全说明禁止无指导灌肠）
- 药物状态追踪（利尿剂与通便药，保存在云端）
- 基于时间的提醒系统（BP 测量、运动时间段与睡前尿检提醒）
- 云端同步（使用 Google Sheets，支持多照护者家庭）
- 乐观式界面（记录即时显示，无需等待服务器响应）
- 每周清洁提醒（内置家务清单）

## 适用对象

- 在家照顾年迈父母或祖父母的家庭成员
- 多人轮班照护的家庭（跨语言沟通）
- 需要严格液体监测的患者（心衰、透析、术后恢复）

## 部署 / 自托管

1. Fork 本仓库
2. 部署你自己的 Google Apps Script 后端（在 `index.html` 中设置 `GAS_URL`）
3. 创建用于存储数据的 Google 表格
4. 在 `index.html` 中更新 `GAS_URL` 与 `SPREADSHEET_URL` 常量
5. 在你的 fork 上启用 GitHub Pages → 完成

## 动机

因亲人需要全天候居家护理且需严格管理液体摄入而开发。现有应用要么复杂、只支持英文，或需付费订阅。本工具旨在简单、双语且免费。
