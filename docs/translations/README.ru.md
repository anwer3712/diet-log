# Sunshine Care Log

> Бесплатный open-source инструмент для ежедневного учета ухода за пожилыми пациентами — для семейных сиделок.

---

## Что это?

Двуязычное (традиционный китайский / индонезийский) веб-приложение для помощи семейным уходящим в отслеживании ежедневных данных о здоровье пожилых людей, особенно при необходимости контроля жидкости.

---

## Функции

- Учет потребления и выделения жидкости, интеллектуальный алгоритм цели мочеиспускания, предупреждение при перегрузке жидкостями
- Логи упражнений, измерения давления и пульса, система оповещений о запорах
