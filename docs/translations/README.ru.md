# Журнал ухода Sunshine / Sunshine Care Log

> Бесплатный инструмент отслеживания ежедневного ухода с открытым исходным кодом для пожилых пациентов — разработан для семейных опекунов.

[![Live Demo](https://img.shields.io/badge/Live-Demo-rose)](https://anwer3712.github.io/diet-log/)

## Что это?

Двуязычное веб-приложение (Традиционный китайский 🇹🇼 / Индонезийский 🇮🇩), разработанное для помощи **семейным опекунам** в отслеживании ежедневных данных о здоровье пожилых пациентов дома — особенно для тех, кто страдает хроническими заболеваниями, требующими строгого контроля жидкости (сердечная недостаточность, диализ, восстановление после операции).

Установка не требуется. Работает в любом браузере смартфона. Данные синхронизируются с Google Sheets через Google Apps Script.

---

## Особенности

- **Отслеживание потребления жидкости** — вода, лекарственные напитки, пищевые добавки, продукты (с суточной целью и полосой прогресса)
- **Отслеживание выделения жидкости** — объем мочи + цвет, стул со статусом
- **Интеллектуальный алгоритм целевого мочеиспускания** — автоматически рассчитывает ожидаемый объем мочи на основе цели потребления воды, корректируется для мочегонных препаратов (диапазон ×1,1–1,5) в сравнении с отсутствием лекарства (диапазон ×0,4–0,6)
- **Предупреждение о перегрузке жидкостью** — красное предупреждение при превышении общего потребления 1200 см3
- **Логирование упражнений** — поднятие бутылок, надавливание стопой, сгибание коленей, помощь при вставании (с контрольным списком протокола безопасности)
- **Артериальное давление и частота пульса** — утренние и вечерние измерения с рекомендациями по измерению
- **Система оповещения о запорах** — автоматически срабатывает каждые 2 часа в течение 60–72 часов после последнего опорожнения кишечника с двуязычными инструкциями безопасности, запрещающими использование клизмы без присмотра
- **Отслеживание статуса лекарств** — мочегонные средства и слабительные, сохраняется в облаке
- **Система напоминания на основе времени** — интеллектуальные напоминания для измерения АД, слотов упражнений и проверки мочи перед сном
- **Облачная синхронизация** — все данные сохраняются в Google Sheets через Google Apps Script; поддерживает домохозяйства с несколькими опекунами
- **Оптимистичный интерфейс** — записи появляются мгновенно без ожидания ответа сервера
- **Еженедельные напоминания об уборке** — встроенное расписание для домашних работ

## Для кого это?

- Члены семьи, ухаживающие за пожилыми родителями или бабушками/дедушками дома
- Домохозяйства с несколькими сменяющимися опекунами (особенно через языковые барьеры)
- Пациенты с заболеваниями, требующими строгого контроля жидкости (сердечная недостаточность, диализ, восстановление после операции)

## Технологический стек

| Слой | Технология |
|-------|-----------|
| Frontend | Ванильный HTML + JavaScript + Tailwind CSS |
| Backend | Google Apps Script (без сервера) |
| База данных | Google Sheets |
| Хостинг | GitHub Pages (бесплатно) |

Никаких фреймворков. Никаких инструментов сборки. Никаких зависимостей для установки. Открывается прямо в любом браузере.

## Установка / Самостоятельный хостинг

1. Сделайте форк этого репозитория
2. Разверните собственный backend Google Apps Script (см. `GAS_URL` в `index.html`)
3. Создайте Google Sheet для хранения данных
4. Обновите константы `GAS_URL` и `SPREADSHEET_URL` в `index.html`
5. Включите GitHub Pages на своем форке → готово

## Мотивация

Создано из необходимости. Когда член семьи нуждался в 24/7 домашнем уходе со строгим контролем жидкости, существующие приложения были либо слишком сложными, либо только на английском, либо требовали ежемесячной подписки. Этот инструмент стремится обеспечить простое, бесплатное и многоязычное решение, чтобы опекуны могли сосредоточиться на пациенте, а не на приложении.

## Дорожная карта

Запланированные улучшения — каждое является открытой проблемой, приветствуется отзыв сообщества:

- [ ] [#15](https://github.com/anwer3712/diet-log/issues/15) **Анализ здоровья с искусственным интеллектом** — интегрируйте Claude для выявления аномальных тенденций в данных потребления жидкости, выделения мочи и артериального давления, а также перевода необработанных данных в простые рекомендации по уходу
- [ ] [#16](https://github.com/anwer3712/diet-log/issues/16) **ИИ опекун Q&A** — позвольте опекунам задавать вопросы на собственном языке (например, "ее моча сегодня была темной, мне беспокоиться?") на основе фактических записанных данных пациента
- [ ] [#17](https://github.com/anwer3712/diet-log/issues/17) **Дополнительные языковые пары** — английский, вьетнамский, тагальский, тайский для многокультурных семей опекунов
- [ ] [#18](https://github.com/anwer3712/diet-log/issues/18) **Автономный режим** — кэширование сервис-воркера для нестабильных соединений
- [ ] [#19](https://github.com/anwer3712/diet-log/issues/19) **Печатные еженедельные отчеты** — сводки на одной странице для посещений врача
- [ ] [#20](https://github.com/anwer3712/diet-log/issues/20) **Поддержка нескольких пациентов** — для домохозяйств или небольших учреждений ухода за более чем одним человеком
