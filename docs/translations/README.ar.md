# سجل رعاية الشمس / Sunshine Care Log

> أداة تتبع الرعاية اليومية مجانية ومفتوحة المصدر لمرضى المسنين — مصممة لمقدمي الرعاية من الأسرة.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Live Demo](https://img.shields.io/badge/Live-Demo-rose)](https://anwer3712.github.io/diet-log/)

---

## ما هذا؟

تطبيق ويب ثنائي اللغة (الصينية التقليدية 🇹🇼 / الإندونيسية 🇮🇩) مصمم لمساعدة **مقدمي الرعاية من الأسرة** على تتبع بيانات صحة المرضى المسنين اليومية في المنزل — خاصة أولئك الذين يعانون من أمراض مزمنة تتطلب إدارة صارمة للسوائل (قصور القلب، قصور الكلى، والتعافي بعد الجراحة).

لا يتطلب تثبيتًا. يعمل على أي متصفح هاتف ذكي. تتم مزامنة البيانات مع جداول بيانات Google عبر Google Apps Script.

---

## الميزات

- **تتبع تناول السوائل** — الماء والمشروبات الطبية والمكملات الغذائية والوجبات (مع الهدف اليومي وشريط التقدم)
- **تتبع إفراز السوائل** — حجم البول + اللون وحركات الأمعاء مع الحالة
- **خوارزمية الهدف البولي الذكية** — تحسب تلقائيًا إفراز البول المتوقع بناءً على هدف تناول الماء، معدلة لأدوية مدرات البول (النطاق ×1.1–1.5) مقابل عدم وجود دواء (النطاق ×0.4–0.6)
- **تحذير الإفراط في السوائل** — تنبيه أحمر عندما يتجاوز إجمالي تناول السوائل 1,200 سم مكعب
- **تسجيل التمارين** — حمل الزجاجات والضغط بالقدم وثني الركبتين والمساعدة في الوقوف (مع قائمة التحقق من بروتوكول السلامة)
- **ضغط الدم ومعدل ضربات القلب** — القياسات الصباحية والمسائية مع إرشادات القياس
- **نظام تنبيه الإمساك** — يتفعل تلقائيًا كل ساعتين بين 60–72 ساعة بعد آخر حركة أمعاء، مع تعليمات السلامة ثنائية اللغة التي تحظر استخدام الحقنة الشرجية دون إشراف
- **تتبع حالة الأدوية** — مدرات البول والملينات، محفوظة في السحابة
- **نظام التذكير المستند إلى الوقت** — تذكيرات ذكية لقياس ضغط الدم والفترات الزمنية للتمارين وفحص البول قبل النوم
- **المزامنة السحابية** — جميع البيانات المحفوظة في جداول بيانات Google عبر Google Apps Script؛ دعم الأسر برعاية متعددة
- **واجهة متفائلة** — تظهر السجلات على الفور دون انتظار استجابة الخادم
- **تذكيرات التنظيف الأسبوعية** — جدول مدمج لمهام نظافة المنزل

---

## من هذا من أجله؟

- أفراد الأسرة الذين يرعاية الوالدين أو الأجداد المسنين في المنزل
- الأسر برعاية متعددة متناوبة (خاصة عبر حواجز اللغة)
- المرضى الذين يتطلبون مراقبة صارمة للسوائل (قصور القلب والغسيل الكلوي والتعافي بعد الجراحة)

## مكدس التكنولوجيا

| الطبقة | التكنولوجيا |
|-------|-----------|
| الواجهة الأمامية | HTML + JavaScript + Tailwind CSS عادي |
| الخلفية | Google Apps Script (بدون خادم) |
| قاعدة البيانات | جداول بيانات Google |
| الاستضافة | GitHub Pages (مجانًا) |

بدون أطر عمل. بدون أدوات بناء. بدون تبعيات للتثبيت. يتم فتحه مباشرة في أي متصفح.

## الإعداد / الاستضافة الذاتية

1. قم بعمل fork لهذا المستودع
2. نشر backend Google Apps Script الخاص بك (انظر `GAS_URL` في `index.html`)
3. إنشاء ورقة Google لتخزين البيانات
4. تحديث ثوابت `GAS_URL` و`SPREADSHEET_URL` في `index.html`
5. تفعيل GitHub Pages على fork الخاص بك → تم

## الدافع

تم البناء من الضرورة. عندما كان أحد أفراد الأسرة يتطلب رعاية منزلية على مدار الساعة مع إدارة صارمة للسوائل، كانت التطبيقات الموجودة معقدة جدًا أو باللغة الإنجليزية فقط أو تتطلب اشتراكات شهرية. يهدف هذا الأداة إلى توفير حل بسيط وخالي من التكاليف ومتعدد اللغات بحيث يمكن لمقدمي الرعاية التركيز على المريض وليس التطبيق.
