# Sunshine Care Log

> Kostenloses Open-Source-Tool zur täglichen Pflegedokumentation für ältere Patienten — für Familienpflegekräfte.

---

## Was ist das?

Eine zweisprachige (traditionelles Chinesisch / Indonesisch) Web-App, die Familienpflegern hilft, tägliche Gesundheitsdaten älterer Patienten zu verfolgen.
