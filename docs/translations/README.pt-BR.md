# Sunshine Care Log

> Ferramenta gratuita e open-source para acompanhamento diário de cuidados de pacientes idosos — feita para cuidadores familiares.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Live Demo](https://img.shields.io/badge/Live-Demo-rose)](https://anwer3712.github.io/diet-log/)

---

## O que é?

Aplicativo web bilíngue (Chinês Tradicional / Indonésio) para ajudar cuidadores familiares a registrar dados de saúde diários de idosos em casa, especialmente para condições que exigem monitoramento de líquidos.

Não requer instalação. Funciona em qualquer navegador de smartphone. Dados sincronizam com Google Sheets via Google Apps Script.

---

## Funcionalidades

- Registro de ingestão e saída de líquidos, algoritmo inteligente de meta de urina, alerta de sobrecarga de líquidos
- Registro de exercícios, medições de pressão arterial e frequência cardíaca
- Sistema de alerta de constipação, rastreamento de medicação, lembretes baseados em horário
