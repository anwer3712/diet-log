# সূর্য যত্ন লগ / Sunshine Care Log

> বয়স্ক রোগীদের জন্য একটি বিনামূল্যে ওপেন-সোর্স দৈনিক যত্ন ট্র্যাকিং টুল — পারিবারিক যত্নশীলদের জন্য ডিজাইন করা।

## এটি কি?

একটি দ্বিভাষিক (ঐতিহ্যবাহী চীনা 🇹🇼 / ইন্দোনেশীয় 🇮🇩) ওয়েব অ্যাপ যা **পারিবারিক যত্নশীলদের** ঘরে বয়স্ক রোগীর দৈনিক স্বাস্থ্য ডেটা ট্র্যাক করতে সাহায্য করার জন্য ডিজাইন করা হয়েছে — বিশেষত যারা দীর্ঘস্থায়ী রোগে ভুগছেন যার জন্য কঠোর তরল ব্যবস্থাপনার প্রয়োজন (হৃদযন্ত্রের ব্যর্থতা, ডায়ালাইসিস, অপারেশন পরবর্তী পুনরুদ্ধার)।

ইনস্টলেশনের প্রয়োজন নেই। যেকোনো স্মার্টফোন ব্রাউজারে কাজ করে। ডেটা Google Apps Script এর মাধ্যমে Google Sheets এ সিঙ্ক করা হয়।

---

## বৈশিষ্ট্য

- **তরল গ্রহণ ট্র্যাকিং** — পানি, ওষুধ পানীয়, পুষ্টি সম্পূরক, খাবার (দৈনিক লক্ষ্য এবং অগ্রগতি বার সহ)
- **তরল আউটপুট ট্র্যাকিং** — প্রস্রাব পরিমাণ + রঙ, মলত্যাগ অবস্থা সহ
- **বুদ্ধিমান প্রস্রাব লক্ষ্য অ্যালগরিদম** — জল গ্রহণ লক্ষ্যের উপর ভিত্তি করে প্রত্যাশিত প্রস্রাব উৎপাদন স্বয়ংক্রিয়ভাবে গণনা করে, মূত্রবর্ধক ওষুধের জন্য সমন্বিত (×1.1–1.5 রেঞ্জ) বনাম কোন ওষুধ নেই (×0.4–0.6 রেঞ্জ)
- **তরল অতিরিক্ত লোড সতর্কতা** — লাল সতর্কতা যখন মোট গ্রহণ 1,200 c.c. অতিক্রম করে
- **ব্যায়াম লগিং** — বোতল উত্তোলন, পায়ের চাপ, হাঁটু বাঁকানো, দাঁড়ানোর সহায়তা (নিরাপত্তা প্রোটোকল চেকলিস্ট সহ)
- **রক্তচাপ এবং হৃদস্পন্দন** — সকাল এবং সন্ধ্যার পরিমাপ পরিমাপ নির্দেশিকা সহ
- **কোষ্ঠকাঠিন্য সতর্কতা সিস্টেম** — শেষ মলত্যাগের 60–72 ঘন্টার মধ্যে প্রতি 2 ঘন্টায় স্বয়ংক্রিয়ভাবে সতর্কতা ট্রিগার করে, দ্বিভাষিক নিরাপত্তা নির্দেশাবলী সহ যা তদারকি ছাড়া এনিমা ব্যবহার নিষিদ্ধ করে
- **ওষুধের অবস্থা ট্র্যাকিং** — মূত্রবর্ধক এবং জোলাপ, ক্লাউডে স্থায়ী
- **সময়-ভিত্তিক অনুস্মারক সিস্টেম** — রক্তচাপ পরিমাপ, ব্যায়ামের স্লট এবং ঘুমের আগে প্রস্রাব পরীক্ষার জন্য স্মার্ট অনুস্মারক
- **ক্লাউড সিঙ্ক** — সমস্ত ডেটা Google Sheets এ Google Apps Script এর মাধ্যমে সংরক্ষিত; বহু-যত্নশীল পরিবারকে সমর্থন করে
- **আশাবাদী ইউআই** — রেকর্ডগুলি সার্ভার প্রতিক্রিয়ার অপেক্ষা না করে তাত্ক্ষণিকভাবে প্রদর্শিত হয়
- **সাপ্তাহিক পরিষ্কার অনুস্মারক** — গৃহস্থালী স্বাস্থ্যবিধি কাজের জন্য অন্তর্নির্মিত সময়সূচী

## এটি কার জন্য?

- পরিবারের সদস্যরা যারা ঘরে বয়স্ক পিতামাতা বা দাদা-দাদির যত্ন নিচ্ছে
- বহু ঘূর্ণনশীল যত্নশীলদের সাথে পরিবার (বিশেষত ভাষা বাধা জুড়ে)
- রোগী যারা কঠোর তরল পর্যবেক্ষণের প্রয়োজন (হৃদযন্ত্রের ব্যর্থতা, ডায়ালাইসিস, অপারেশন পরবর্তী পুনরুদ্ধার)

## সেটআপ / স্ব-হোস্টিং

1. এই রিপোজিটরি ফর্ক করুন
2. আপনার নিজের Google Apps Script ব্যাকএন্ড স্থাপন করুন (`index.html` এ `GAS_URL` দেখুন)
3. ডেটা স্টোরেজের জন্য Google Sheet তৈরি করুন
4. `index.html` এ `GAS_URL` এবং `SPREADSHEET_URL` ধ্রুবক আপডেট করুন
5. আপনার ফর্কে GitHub Pages সক্ষম করুন → সম্পূর্ণ

## প্রেরণা

প্রয়োজনের বাইরে তৈরি। যখন একজন পরিবারের সদস্যকে কঠোর তরল ব্যবস্থাপনার সাথে 24/7 ঘর বসে যত্নের প্রয়োজন ছিল, বিদ্যমান অ্যাপ্লিকেশনগুলি খুব জটিল, শুধুমাত্র ইংরেজিতে বা মাসিক সাবস্ক্রিপশন প্রয়োজন। এই টুলটি একটি সহজ, বিনামূল্যে, বহুভাষিক সমাধান প্রদান করার লক্ষ্য রাখে যাতে যত্নশীলরা রোগীর উপর ফোকাস করতে পারে, অ্যাপ নয়।
