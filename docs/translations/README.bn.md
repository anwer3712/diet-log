# বাংলা

নোট: এই ফাইলটি মেশিন অনুবাদ করা হয়েছে; মানবীয় প্রুফরিড প্রয়োজন।

# Sunshine Care Log

> বয়স্ক রোগীদের জন্য একটি বিনামূল্যের ওপেন-সোর্স দৈনিক কেয়ারের ট্র্যাকিং টুল — পারিবারিক পরিচর্যাকারীদের জন্য।

---

## এটি কী?

একটি দ্বিভাষিক (প্রচলিত চাইনিজ / ইন্দোনেশীয়) ওয়েব অ্যাপ যা বাড়িতে বয়স্ক রোগীদের দৈনিক স্বাস্থ্য তথ্য অনুসরণ করতে পরিবারিক পরিচর্যাকারীদের সাহায্য করে, বিশেষ করে যারা তরল পদার্থ নিবন্ধন প্রয়োজন।

---

## বৈশিষ্ট্য

- তরল গ্রহণ এবং বাহির রেকর্ডিং, বুদ্ধিমান মূত্র লক্ষ্য অ্যালগরিদম, তরল অতিপ্রবাহ সতর্কতা
- ব্যায়াম লগিং, রক্তচাপ ও হৃদস্পন্দন পরিমাপ
