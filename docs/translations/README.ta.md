# தமிழ்

கவனம்: இந்த கோப்பு இயந்திர மொழிபெயர்ப்பால் உருவாக்கப்பட்டது; மனித ஆய்வு தேவை.

# Sunshine Care Log

> முதியோர் நோயாளிகளுக்கான இலவச திறந்த மூல தினசரி பராமரிப்பு கண்காணிப்பு கருவி — குடும்ப கவனையாளர்களுக்காக.

---

## இது என்ன?

வீட்டில் முதியோரின் தினசரி சுகாதார தரவுகளை பின்தொடர உதவும் இருதொழில்நுட்ப சமையல் (சீன மரபு / இந்தோனேஷியன்) வெப் பயன்பாடு.
