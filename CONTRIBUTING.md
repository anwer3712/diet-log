# Contributing to Grandma Care Log

Thank you for your interest in improving this home-care tool! This project exists to help family caregivers everywhere, and contributions of all kinds are welcome.

## Ways to Contribute

### 🐛 Report Bugs
Open an [issue](https://github.com/anwer3712/diet-log/issues) with:
- What you expected to happen
- What actually happened
- Your device / browser

### 🌍 Translations
The app is currently bilingual (Traditional Chinese / Indonesian). We would love help adding more language pairs for multicultural caregiving households — English, Vietnamese, Tagalog, Thai, and others are all welcome.

### 💡 Feature Requests
If you care for an elderly family member and need a feature, open an issue describing your caregiving scenario. Real-world caregiver needs drive this project's roadmap.

### 🔧 Code Contributions
1. Fork the repository
2. Make your changes to `index.html` (the app is intentionally a single self-contained file — no build step)
3. Test in a mobile browser (the primary target is smartphone use at bedside)
4. Open a pull request with a clear description

## Design Principles

Please keep these in mind — they exist because of real caregiving constraints:

1. **Single file, zero build** — caregivers self-host by forking; nothing to compile
2. **Mobile-first** — used one-handed at bedside, often in a hurry
3. **Bilingual always** — every user-facing string needs both languages
4. **Safety warnings are non-negotiable** — medical alert logic (fluid limits, bowel movement alerts, standing protocols) must never be weakened without medical justification
5. **Free forever** — no features that require paid services beyond a free Google account

## Medical Disclaimer

This tool assists record-keeping only. It does not provide medical advice. Alert thresholds were set based on physician guidance for a specific patient; contributors should not present them as universal medical standards.

## Questions?

Open an issue — happy to discuss anything.
